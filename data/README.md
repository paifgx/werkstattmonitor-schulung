# Synthetische Messwerte

Alle Werte sind frei erfunden. `normal.csv` enthält fünf Anzeigenzustände.
`invalid.csv` enthält drei absichtliche Eingabefehler. Keine Steuerungsbefehle,
keine Schnittstelle zu Geräten, keine Kundendaten. Wertebereiche sind ausschließlich
ein Übungsvertrag und keine Vorgaben für reale Maschinen.
